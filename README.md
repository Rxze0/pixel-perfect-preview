# SitABit

**Find your vibe, eat safely, book the right table.**

SitABit is a mobile-first restaurant companion with two sides:

## For guests
- **Pick a restaurant** — Bella Italia, Fuego & Smoke or Sakura & Sea, each with its own concept, menu and colours.
- **Who's coming?** — add everyone at the table with their food restrictions.
- **Tonight** — a live 2.5D floor plan, zones ranked by how well they fit your occasion, and the best times to come.
- **Menu** — every dish with ingredients, calories, protein, fat and carbs, with category filters.
- **Book a table** — tap a free table on the room map and pick a time (account required).
- **After your visit** — quick feedback or your own written review, and saving favourite dishes.

## For restaurants
- **Quick staff sign-in** with name and PIN.
- **Tables** — who's sitting where, occasion, restrictions, favourite dishes and one gentle pairing suggestion.
- **Owner insights** — zone occupancy, quiet hours, returning guests, visit rhythm, feedback breakdown and regular guests.
- **Win back guest** — a personal offer for guests who haven't visited in a while, ready to send via WhatsApp.

## Tech
React 19 · TanStack Start · TypeScript · Tailwind CSS · Supabase (accounts, bookings, feedback)

## Run locally
```sh
bun install
bun run dev
```

## GitHub Pages
Every push to `main` builds and publishes the site automatically
(`.github/workflows/deploy-pages.yml`). In the repository go to
**Settings → Pages → Source** and choose **GitHub Actions** once.
